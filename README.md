## ☁️ What is Cloud Computing? (Quick Reference)

**The cloud is computing power you rent — like electricity.**

You do not build a power station to charge your phone. You plug in and pay for what you use. Cloud works the same way.

**Three layers:**
1. **Your device** — phone, laptop, tablet
2. **The internet** — the highway that connects you
3. **Data centres** — massive buildings filled with servers (AWS has them in Cape Town 🇿🇦)

**You already use the cloud every day:**
- 🎵 Spotify — music from the cloud
- 🎬 Netflix — video from the cloud
- 💰 M-Pesa — banking on the cloud
- 📸 Instagram — photos in the cloud
- 💬 WhatsApp — messages via the cloud
- 📧 Gmail — email in the cloud

## 💼 What Does a Solutions Architect Do?

A Solutions Architect is a **translator between people and technology**. They:
- Meet with customers to understand their challenges
- Design cloud solutions using AWS services
- Present and explain solutions in simple language
- Help teams build and launch
- Learn new services constantly
- Mentor others

> You need to be a great communicator and creative problem solver. This role is as much about people as it is about technology.
